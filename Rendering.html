SVG geometry and raster filters

Clipping accepts paths, basic shapes, text and local use references. Child silhouettes are united, clip-rule is inherited, transforms are applied, and clipPathUnits="objectBoundingBox" maps normalized content to the target's geometric bounds. Empty clips hide their targets. Definitions and circular references do not paint.

Nested svg elements establish independent percentage-length contexts, viewport position/dimensions, viewBoxes, meet/slice/none aspect ratios and overflow clipping. Symbol viewBoxes also establish the percentage context for their content. Local use references preserve their target's parent after rendering and circular references are ignored.

textPath lays out glyph outlines along a referenced path, rotates them to the path tangent, and supports startOffset (including percentages), text anchoring and nested styled spans. Glyphs whose midpoints are outside the path are omitted. This does not implement text stretching/automatic spacing, vertical text-on-path or pathLength calibration.

Patterns support independent patternUnits and patternContentUnits, tile origin/dimensions, viewBox/aspect ratio, transforms, opacity and local href templates (including forward references). Brushes are constructed per target bounds, so sharing a pattern between differently sized objects is safe. Circular pattern painting returns transparent content. Pattern overflow is clipped to the tile.

feTurbulence and feDisplacementMap use a bounded CPU raster pipeline. Turbulence provides four seeded channels, turbulence/fractalNoise, one or two base frequencies, up to nine octaves and tile stitching, using the SVG 1.1 noise generator. Displacement uses unpremultiplied R/G/B/A selectors, signed scale and bilinear sampling with transparent pixels outside the input.

Standalone filters and chains support SourceGraphic/SourceAlpha, named results, primitive subregions, filter/primitive coordinate units, sRGB/linearRGB conversion, flood, offset, merge, composite, color matrices (including saturation, hue rotation and luminance-to-alpha), component transfer, blend, Gaussian blur, morphology and tile. Component transfer implements identity, linear, gamma, table and discrete functions on unpremultiplied channels. Blend implements separable and nonseparable CSS blend modes. Gaussian blur uses three separable box convolutions, keeping work linear in the image size even for large radii. Morphology uses sliding extrema for erosion/dilation. Tile repeats the input subregion, including its transparent pixels. Unsupported primitive types are currently passed through; this is not a complete SVG filter graph implementation. Single matrix/saturation filters retain a vector paint mapping when native animations are enabled to preserve child clocks.

Element opacity is applied after the filter; fill/stroke opacity is part of SourceGraphic. Radial gradients retain their focal point in the same coordinate space as the center, and gradient/pattern brushes preserve per-use opacity. CSS colors accept RGB/RGBA, HSL/HSLA, percentage channels and short/long RGBA hex notation. Gradient stops clamp offsets monotonically, and gradients honor pad/repeat/reflect spreading.

SVG path data is parsed segment by segment, including single-token adjacent arc flags and reflected curve controls. Invalid data stops the current path at its last complete segment instead of aborting the SVG. Polygon/polyline lists likewise retain valid pairs before invalid data and ignore an unmatched final coordinate. Empty paths and point lists are safe.

Raster filters sample the source at load time; animation of the filtered source or filter parameters does not update their bitmap. Rasterization uses up to four pixels per user unit and a maximum dimension of 2048 pixels. This bounds memory use but limits magnification quality. The geometry and animation features remain vector-based outside these raster filter chains.

Run the regression runner with RESVG_TEST_SUITE pointing to a local checkout of linebender/resvg-test-suite to additionally compare path, polygon/polyline and supported filter cases against its reference PNGs. The huge-blur, transformed-tile and two out-of-range saturation fixtures are checked for successful rendering only: the huge-blur reference has implementation-specific artifacts and the other fixtures are explicitly marked undefined behavior upstream. Image comparisons allow small rasterization differences, with a wider tolerance for repeated tile edges and fractional morphology radii. Reference SVGs/PNGs and downloaded animation examples are kept outside this repository.
